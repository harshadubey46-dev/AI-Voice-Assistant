# 🎙️ AI Voice Assistant

An AI-based voice assistant developed in Python that accepts voice commands, processes them, and performs useful tasks such as providing the current time and date, opening websites, searching Google, and retrieving information from Wikipedia.

## ✨ Features

- 🎤 Voice input using SpeechRecognition
- 🔊 Voice responses using pyttsx3
- 🕐 Tells the current time
- 📅 Tells the current date
- 🌐 Opens Google, YouTube and GitHub
- 🔎 Searches Google
- 📚 Retrieves information from Wikipedia
- 👋 Supports exit commands such as "bye", "goodbye", "exit" and "stop"
- ❌ Handles unknown commands with a helpful response

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Wikipedia API
- Webbrowser
- Datetime
